01 · One notebook core

Text and ink stay close to the thought.

The default canvas supports direct writing, drawing, arranging, undo, print, and fast local search. Mind maps are an optional built-in note type and load only when opened.

01 / CANVAS

Spatial by default

Place editable text and ink anywhere. Pages expand around the work while familiar paper boundaries remain visible.

02 / VOICE

Transcript, not recordings

Local voice capture streams temporary audio for transcription. Personal Note saves only editable final text and never retains audio media.
