Personal Note · prettier Settings, search and note icons

Claude's version, drawn with the Paper skin's real colours and fonts. Cosmetic only: the same features, places and keys. Every note gets an emoji in a soft tinted tile, like Notion pages; the app guesses one from the title (as it already does for notebook icons), and you can change it.

1 · Notes with colourful emoji icons

The notes list shows each note's emoji in a tinted tile (the tint comes from the skin's five object colours, so it changes with Paper, Crayon and Night). The open page shows the emoji big above its title, like a Notion page. Clicking either opens the picker: search, recent, a few dozen common emoji, five tints, "Remove" and "Guess from title".

2 · Search results

The search box opens in the middle, like Spotlight or Raycast, a little wider. Each result shows its emoji, the title and a line of the text around the match (both marked like a highlighter), its notebook and when it was last changed. A match found only by meaning says so. On desktop, the selected note shows a preview on the right, so you can check it before opening it.

3 · Settings

Settings becomes its own window, laid out like macOS System Settings: sections on the left, each with a coloured icon tile, and grouped cards with real switches on the right. The open note's properties (notebook, type, storage) move out of it into a small popover on the title island, so Settings only holds app-wide choices. On a phone it's an iOS-style list that drills into each section. Try the switches and the AI choice.
