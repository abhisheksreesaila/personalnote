## Next fixes (F-034)
- Never build a page on the spot when its estimated cost exceeds one frame; use vectors for that zoom/pan instead (classic zoom is fine on normal notes).
- Idle page builds: real splitting (build a page from an object subset per slice, or a hidden Leafer per page), and never start a slice within ~300 ms of input or while a key/pointer is active.
- Pan right after an edit: if the dirty pages' estimated rebuild exceeds a frame, stay on vectors for the window instead of mixing.
