Engine Showdown

The same Personal Note desk drawn three times: by Fabric.js (Canvas 2D, what the app uses today), by LeaferJS (Canvas 2D with an editor plugin and partial redraw) and by PixiJS (WebGL). Pan, zoom, select, drag, draw and edit in each and compare how they feel. One engine at a time is the fair comparison.

What to try

  • Two-finger scroll (or the mouse wheel) to pan. Ctrl or ⌘ + wheel, or a trackpad pinch, zooms to the pointer. Hold Space and drag (or drag with the middle button) to pan. In Pixi, dragging empty desk also pans.
  • In Fabric and Leafer, drag across empty desk to box-select, and Shift-click to add to a selection. Drag the selection: the arrows follow. Use the corner handles to resize and the rotate handle (Fabric) or the area just outside a corner (Leafer) to rotate.
  • Pick Pen and write on a page.
  • Double-click a text label or a sticky to edit its text.
  • Switch to Leafer only or Pixi only at 50k or 100k, zoom out to see every page, then pan quickly. Watch the slowest-frame number. Then zoom in on one page and drag a sticky: that is where Leafer's region redraw pays off.
  • Zoom in close on a label in each bay and compare how sharp the text is.

What each engine is

Fabric.js redraws every visible object with Canvas 2D on every frame that changes anything. It skips off-screen objects and caches some as bitmaps. Selection, handles, text editing and the pen are built in. It is not built at 10,000 objects and above here: we already know it struggles there.

LeaferJS also draws with Canvas 2D on the CPU, not the GPU, but it redraws only the regions that changed: dragging a sticky repaints a rectangle around it, not the page. Panning and zooming change every pixel, so those are full redraws of what is on screen. Selection, transform handles, box select, text editing and arrows come from its official editor plugins. It has no built-in undo or freehand brush.

PixiJS uploads shapes and ink to the GPU once and then only moves one container to pan and zoom. It is a drawing engine only: no selection, no handles, no text editing, no serialization. Every one of those would be app code, so this bay has a plain outline instead of handles.

How editing works in each

Fabric edits text on the canvas itself with a hidden text box feeding it keystrokes. Leafer lays a real browser text box over the text while you type (its text editor plugin), then draws the result back into the canvas. Pixi cannot edit text, so this demo does the same overlay trick by hand: Enter or Esc commits a label, Shift+Enter adds a line.

The Leafer pen is app code on top of Leafer (it has no brush tool): it adds one path and updates it as you move, and Leafer repaints only the stroke's area. Fabric's pen is its built-in brush. Neither Fabric nor Leafer ships undo and redo; both would need an app-side history.
