# Context: Personal Note vocabulary

- **Canvas note**: the free-form note (JSON Canvas); text boxes, ink, shapes, images and connectors placed anywhere on growing pages.
- **Mind map note**: the lazy-loaded map editor.
- **Page note**: the writing-first note: Markdown text that flows, with an ink layer on top. The default new note from Milestone 1.
- **Text layer**: the page note's Markdown. Canonical, clean, what search, export and agents read.
- **Ink layer**: everything drawn on a page note, stored beside the Markdown.
- **Mark**: ink drawn on words (circle, underline, highlight) or in the side margin; anchored to a word or line and moves with it.
- **Drawing**: a standalone object in the page's flow made by drawing on empty space; holds strokes, shapes and text objects. Linked to no word unless the user links it.
- **Text object**: free-placed text inside a drawing (word art), not part of the Markdown.
- **Link word**: the word a drawing is linked to; shown in teal when the drawing can fold behind it.
- **Fold / unfold**: hide a linked drawing behind its link word / slide it back out.
- **Loose ink**: a mark whose words disappeared in an agent rewrite; kept in a tray, never deleted silently.
